# Project Definition

Complete this document when beginning a project.

## Purpose

What problem does this project solve?

## Users and stakeholders

Who uses, operates, funds, or is affected by it?

## Desired outcomes

What measurable outcomes define success?

## Scope

What is included, and what is explicitly excluded?

## Constraints

Record business, technical, regulatory, schedule, and compatibility constraints.

## Domain language

Define important terms consistently.
