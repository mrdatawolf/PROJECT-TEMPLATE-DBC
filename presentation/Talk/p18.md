[Slide 18 — roles as specialists]

And the roles are specialists, not one generalist agent wearing every
hat — the same argument for small composable Unix tools applies here.
Human owns goals, priorities, architecture, acceptance. Architect
clarifies requirements, proposes architecture, decomposes work. Contract
designer turns approved designs into precise behavioral contracts.
Implementer satisfies the contract — does not invent it. UX specialist
owns interaction design, accessibility, frontend behavior. Reviewer
verifies compliance, regressions, security — independent of
implementation, always.

I do this by using Codex to code, Claude to help me architect and contract,
Copilot for initial images and pretty words.
