## How it's actually implemented

[Slide 16 — the state machine]

A task's directory is its state. No status field to drift out of sync
with reality — filesystem location is the single source of truth. If
you've ever trusted `/proc` over whatever a management API told you, you
already believe in this pattern. Flow: proposed → approved (human) →
in-progress (agent assigned) → review (handoff) → completed (acceptance).
And review can bounce back to in-progress on changes requested — that's
the one cycle in the graph.
