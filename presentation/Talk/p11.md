## The problem this is actually solving

[Slide 11 — "AI coding agents are fast. That's not the same as trustworthy."]

You've all seen this shape of failure already, probably this week:

- Scope creep — ask for a bug fix, get a "helpful" refactor of three
  unrelated files.
- Silent architecture decisions — a real design choice buried inside a
  diff instead of surfaced for review.
- No memory across sessions — every new chat re-derives context from
  scratch, or worse, re-decides something that was already settled.
- Unreviewable output — "it works" is not the same claim as "it satisfies
  the requirement," and there's often no artifact to check it against.

The `git blame` joke practically writes itself: three weeks later a
teammate asks why `auth.js` checks `isAdmin` three different ways, and the
answer is sitting in a chat window that no longer exists. That's not an AI
problem specifically — it's an old problem AI made faster and more
frequent.
