Same discipline applies to architecture decisions, not just task-level
contracts. ADR-002, PGlite worker-thread pattern: "PGlite's WASM initdb
aborts when called directly on Windows, so we always spin it up inside a
worker thread." Benefit: works around a hard platform blocker. Cost: every
query now crosses a thread boundary. Open question, recorded, not hidden:
is this still needed on non-Windows platforms? A decision made once,
recorded once, with its actual trade-offs — instead of getting silently
re-litigated, or silently reversed, by whichever agent touches the file
next.
