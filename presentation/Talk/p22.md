[Slide 22 — living memory]

The repository is the memory. The chat is not. Every contract, ADR, and
task file outlives the conversation that produced it — the next agent, or
the next human, reads the repo, not a transcript. `docs/contracts` for
approved behavior, `docs/decisions` for ADRs — the why, not just the what
— `docs/roles` for what each specialist owns, `docs/workflow` for
lifecycle and gates. Even API promises to external consumers get the same
treatment: "an API promise is a contract — given valid input, the server
commits to a specific output" — versioned in git, not living in someone's
memory of a stand-up.
